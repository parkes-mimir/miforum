# 更新日志模板

新增版本时复制此模板，粘贴到 `CHANGELOG.md` 文件顶部（`---` 分隔线之后），书写请阅读书写规范。

```markdown
## [X.Y.Z] - YYYY-MM-DD - 贡献者1, 贡献者2

### 新增
- 新增功能和代码描述

### 修复
- Bug修复描述

### 安全
- 安全漏洞修复

### 变更
- 功能和代码旧换新描述

### 重大变更
- 架构旧换新描述

### 删除
- 删除的功能和代码描述
```

---

## 书写规范

1. **每条一行**：使用中文简洁描述做了什么
2. **不要重复**：同一修复只在一个版本中出现
3. **贡献者格式**：GitHub 用户名，多人用逗号分隔
4. **日期格式**：YYYY-MM-DD
5. **版本号**：遵循语义化版本（SemVer）
6. **注意事项**：未推送版本相比上一版本新增功能的变更、修复、安全不写入更新日志
```
